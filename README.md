# 🎂 הבינגו של אילה

משחק בינגו רב-משתתפים בזמן אמת ליום ההולדת הראשון של אילה.
Next.js + TypeScript + Tailwind, עם Supabase לסנכרון בין הטלפונים, ומתפרסם ב-Vercel.

---

## חלק 1: מסד נתונים חדש ב-Supabase (בערך 5 דקות)

כבר יש לך חשבון, אז רק פותחים **פרויקט חדש** (בחשבון החינמי אפשר עד 2 פרויקטים פעילים).

1. נכנסים ל-https://supabase.com/dashboard ומתחברים.
2. לוחצים **New project**.
   - אם מופיעה בחירת Organization, בוחרים את הקיימת.
   - **Name:** `ayala-bingo`
   - **Database Password:** לוחצים Generate ושומרים את הסיסמה בצד. לא נצטרך אותה בהמשך, אבל טוב שתהיה.
   - **Region:** בוחרים אזור קרוב, למשל `Central EU (Frankfurt)`.
   - לוחצים **Create new project** ומחכים בערך דקה עד שהפרויקט מוכן.
3. **יוצרים את הטבלאות:** בתפריט השמאלי לוחצים **SQL Editor**, ואז **New query**.
   פותחים את הקובץ [`supabase/schema.sql`](supabase/schema.sql) מהפרויקט הזה, מעתיקים את **כל** התוכן, מדביקים ולוחצים **Run**.
   אמורה להופיע ההודעה `Success. No rows returned`.
4. **מעתיקים את שני המפתחות:** בתפריט השמאלי **Project Settings**, ואז **API Keys** (או **Data API**).
   - **Project URL**, שנראה כמו `https://abcdefgh.supabase.co`. אם הוא לא מופיע שם, הוא נמצא בכפתור **Connect** שבראש הדף.
   - **המפתח הציבורי:** `anon public`, או בפרויקטים חדשים `Publishable key` (מתחיל ב-`sb_publishable_`).
   - ⚠️ **לא** להשתמש במפתח `service_role` או ב-`secret`. אלה מפתחות סודיים.

> המפתח הציבורי בטוח לשימוש בדפדפן: כל ההגנות (מי רואה איזה כרטיס, מה מותר לסמן, מי יכול להגריל) יושבות בתוך מסד הנתונים.

## חלק 2: פרסום ב-Vercel (בערך 5 דקות)

1. נכנסים ל-https://vercel.com/signup ונרשמים עם **Continue with GitHub**.
2. לוחצים **Add New… → Project**.
3. ברשימה בוחרים את הריפו `Bingo` ולוחצים **Import**.
   אם הוא לא מופיע, לוחצים **Adjust GitHub App Permissions** ונותנים ל-Vercel גישה לריפו.
4. פותחים את **Environment Variables** ומוסיפים שני משתנים:

   | Key | Value |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | ה-Project URL מ-Supabase |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | המפתח הציבורי מ-Supabase |

5. לוחצים **Deploy**, ואחרי כדקה-שתיים מתקבל קישור כמו `https://bingo-xxxx.vercel.app`. 🎉

**שינוי שם לקישור (לא חובה):** ב-Vercel נכנסים ל-**Settings → Domains**, ואפשר להגדיר כתובת כמו `ayala-bingo.vercel.app`.

**חשוב:** Vercel מכניס את המשתנים לאתר רק בזמן הבנייה. לכן אחרי כל שינוי שלהם חייבים לפרסם מחדש.
- `NEXT_PUBLIC_SUPABASE_URL` הוא **הכתובת**, למשל `https://abcd1234.supabase.co`. את `abcd1234` רואים בשורת הכתובת של Supabase, אחרי `project/`.
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` הוא **המפתח**, שמתחיל ב-`eyJ...` או ב-`sb_publishable_...`.

**אם שכחת משתנה או שינית אותו:** נכנסים ל-**Deployments**, לוחצים על שלוש הנקודות ליד הפרסום האחרון, ואז **Redeploy**.

## חלק 3: בדיקה לפני המסיבה ✅

1. **שלושה חלונות:** פותחים את האתר במחשב ולוחצים "אני מנהל/ת הבינגו".
   את הקישור שמתקבל פותחים בשני חלונות גלישה בסתר נוספים (או בטלפון), ונרשמים בכל אחד כשחקן עם שם ודמות.
   ✔️ השחקנים מופיעים מיד בחדר ההמתנה אצל כולם.
2. **התחלה והגרלה:** לוחצים "התחל משחק" ואז "הגרל מספר".
   ✔️ המספר מופיע עם אנימציה בכל החלונות.
3. **סימון לא חוקי:** לוחצים בכרטיס של שחקן על מספר שעוד לא הוגרל.
   ✔️ מופיעה ההודעה "המספר הזה עוד לא הוגרל" והמספר לא מסומן.
4. **"האם פספסתי מספר?":** מגרילים כמה מספרים ולא מסמנים.
   ✔️ לחיצה על הכפתור גורמת למספרים שפספסת להבהב, אבל לא מסמנת אותם.
5. **רענון:** מרעננים את הדף של שחקן.
   ✔️ חוזרים אותו שחקן, עם אותו כרטיס ואותם סימונים.
6. **הצטרפות באמצע:** פותחים חלון רביעי ומצטרפים אחרי שכבר הוגרלו מספרים.
   ✔️ השחקן החדש מקבל כרטיס רגיל ורואה את היסטוריית המספרים.
7. **תיקו וסיום:** כדי להגיע מהר לניצחון, ממשיכים להגריל ולסמן.
   - ✔️ כשמישהו מסיים, כולם רואים הודעה חגיגית.
   - ✔️ כששני שחקנים מסיימים אחרי אותו מספר, שניהם במקום 1, והבא אחריהם במקום 3.
   - ✔️ כשיש 3 מנצחים מופיעה ספירה לאחור של 15 שניות, וכפתור ההגרלה נחסם.
   - ✔️ בסוף הספירה מופיע הפודיום עם קונפטי ו"מזל טוב אילה!".
8. **משחק חדש:** המנהל לוחץ "משחק חדש".
   ✔️ כולם חוזרים לחדר ההמתנה עם כרטיס חדש.

💡 **טיפ לבדיקה מהירה:** אם יש רק שחקן אחד או שניים, אי אפשר להגיע ל-3 מנצחים. אפשר ללחוץ אצל המנהל על "סיום המשחק עכשיו" כדי לראות את הפודיום.

## איך זה עובד (בקצרה)

- **`supabase/schema.sql`:** כל חוקי המשחק יושבים כאן, בתוך מסד הנתונים.
  - הכרטיסים שמורים בטבלה סודית שאי אפשר לקרוא מהדפדפן.
  - כל שחקן מקבל טוקן סודי, שנשמר ב-localStorage של הטלפון שלו.
  - סימון מספר עובר דרך הפונקציה `mark_number`, שבודקת שהמספר הוגרל ושהוא באמת בכרטיס.
  - להגריל יכול רק מי שמחזיק את הטוקן של המנהל.
- **`src/app/page.tsx`:** מסך הכניסה.
- **`src/app/host/[code]/page.tsx`:** מסך המנהל.
- **`src/app/play/[code]/page.tsx`:** מסך השחקן.
- **`src/lib/useRoom.ts`:** מאזין לשינויים בזמן אמת (Supabase Realtime). בנוסף הוא מרענן כל 4 שניות, למקרה שהטלפון נרדם וניתק.

### הרצה במחשב (לא חובה)

```bash
npm install
cp .env.example .env.local   # וממלאים את שני המשתנים
npm run dev                  # http://localhost:3000
```
